# BP1P Production 1.0.0

- Replaced direct WebRTC/ICE production transport with deployable HTTP(S) proxy nodes.
- Added one-file `BP1P.html` proxy client.
- Added Ed25519 directory manifest signing and client-side signature verification.
- Added Ed25519 node identities and signed node registration.
- Added pending/approved/revoked community-node trust states.
- Added polished localhost Node Console for application setup.
- Added localhost Directory Console for node approval/revocation.
- Added one-click Windows setup/start/stop/update/logs/pair launchers.
- Added all-in-one public Caddy profile and node-only community deployment profile.
- Added upstream allowlisting and private-address protection by default.
